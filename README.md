# Python Fundamentals and Algorithms

Colección de programas desarrollados en Python para practicar fundamentos de programación, validación de datos, estructuras FIFO, diseño de algoritmos e interpolación polinomial.

## Contenido

El repositorio incluye implementaciones de:

- Variables, operadores y tipos de datos.
- Cadenas y listas.
- Condicionales y ciclos.
- Funciones y valores de retorno.
- Validación de entradas con manejo de excepciones.
- Generación de números primos.
- Implementación y ordenamiento de una cola.
- Evaluación de polinomios interpolantes.
- Construcción de polinomios mediante una relación de recurrencia.
- Operaciones algebraicas con polinomios representados mediante listas.
